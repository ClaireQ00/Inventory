# 角色协作场景模拟与工作 SOP

> 版本：2026-08-14 ｜ 基于系统真实流程（报价→合同→生产/外协入库→发货→出库→报关→收款）
> 角色：**客户**（外部）、**业务员**、**生产调度员**、**出入库保管员**
> 系统入口：录入端 8082（录单）｜ 查询端 8501（看数、链路图、关行）

---

## 一、场景模拟（5 个典型情况）

### 场景 1：标准全流程（参考真实单 BL-2608）

```
7-28 客户询价 → 业务员录报价（YL…-brief）
7-30 客户确认 → 报价转合同 SC…001（系统提示缺标签纸 → 业务员通知采购）
8-01~07 生产调度员排产 → 完工后保管员录生产入库 IN…（本厂 WH-01）
8-07 调度员通知发临沂中转 → 保管员录调拨出库 OUT… + 调拨入库 IN…（WH-03，同一调拨号配对）
8-08 业务员开预制发货单 DN…（draft，计划数）→ 装柜 → 保管员回填实发数 → 确认
      → 保管员录销售出库 OUT…（关联 DN）→ 业务员安排报关
9-10 客户付款 → 业务员录收款 RC…（系统按当月汇率折 CNY）
```

### 场景 2：装柜损耗（计划 100 卷，实装 95 卷）

- 预制发货单数量 100 → 装柜只能装 95
- 保管员**回填 actual_quantity=95**，系统自动算 short_qty=5
- 系统所有统计（提成、应收、校验）只认 95
- 业务员跟客户确认：剩下 5 卷是补发还是放弃
  - 补发 → 下次发货单继续发这行（未发量还有 5）
  - 放弃 → 业务员在 8501 关行（见场景 4）

### 场景 3：外协（自己不做，外发加工）

- 合同里有外协物料 → 生产调度员下采购单 PO → 外协厂送货 → 保管员录**采购入库**（in_type=purchase）
- 系统「合同进度」的"已入库"把自产+外协合并显示，业务员一眼看到齐套情况

### 场景 4：客户中途改主意（3 种料里 1 种不要了）

- 客户电话："1-3/4 寸剩下 69 卷不要了，其他两种照常"
- 业务员：8501 → 合同执行 → 选合同 → **关闭合同行** → 填原因（"客户 8/14 电话确认放弃余量"）
- 系统动作：该行余量从所有"还欠/缺口"统计消失、禁止再发货、备注留痕
- 生产调度员：该物料停产/改排其他合同；保管员：库存转大池子

### 场景 5：同一物料供两张合同（抢库存）

- M-Q0025-002 同时挂在 A、B 两客户的合同里
- 业务员在 8501「同一物料跨合同分布」看到：A 欠 50 + B 欠 80 = 130，池子只剩 55 → 缺 75
- 业务员之间协商优先级 → 生产调度员补排产 75 卷
- **规矩：先到先得只看发货单确认顺序，不在系统里锁库存**——谁先发柜谁先出池子

| 时间节点 | 角色 | 做什么事 | 系统操作 | 跟谁沟通什么 |
|---|---|---|---|---|

## 三、各角色 SOP

### SOP-1 业务员

**Owner：业务员本人 ｜ 系统主用：8082 录入 + 8501 查询**

| 步骤 | 动作 | 系统操作 |
|---|---|---|
| 1 | 新客户建档 | 客户录入（编码自动推荐，不要手改格式：字母+4位数字） |
| 2 | 新产品确认规格 | 物料录入（填内径/厚度/长度，单重外径自动算） |
| 3 | 报价 | 报价录入；卷价可手改，以手填为准 |
| 4 | 转合同 | 合同录入；**必看辅料缺口提示**，缺料通知采购 |
| 5 | 要货 | 发货单（计划数）；关联合同行号 |
| 6 | 发货后 | 跟保管员核对实发数；有差异跟客户确认补发/放弃 |
| 7 | 放弃余量 | 8501 关行，**原因必填** |
| 8 | 收款 | 收款录入；关联合同；汇率自动取当月 |
| 9 | 每周自查 | 8501：我的客户订单总览 + 未发完合同 + 提成基数 |

**红线**：不替仓库回填实发数；不手改客户编码格式；关行必须填原因。

### SOP-2 生产调度员

| 步骤 | 动作 | 依据 |
|---|---|---|
| 1 | 接单排产 | 8501 合同进度：合同数 − 已入库 = 待产 |
| 2 | 外协决策 | 自产做不完的走采购入库线 |
| 3 | 跨合同抢料 | 8501 同一物料跨合同分布：缺口 >0 才排产 |
| 4 | 完工移交 | 告诉保管员完工数量（保管员录入库） |
| 5 | 异常 | 关行的料立即停产；超产入库照常录，库存进大池子 |

### SOP-3 出入库保管员

| 步骤 | 动作 | 系统操作 |
|---|---|---|
| 1 | 入库点收 | 入库单：自产=production / 外协=purchase / 中转到达=transfer |
| 2 | 备货 | 看 draft 发货单=备货指令 |
| 3 | 装柜 | 实际装多少数多少 |
| 4 | **回填实发数** | 发货单 actual_quantity，**当天必做**，忘填全系统数据失真 |
| 5 | 出库扣账 | 出库单；销售出库必须关联发货单号；调拨必须填调拨号配对 |
| 6 | 辅料领用 | 生产领标签纸走辅料出库（此时才扣辅料库存） |

**红线**：先有入库才有出库；实发数自己数自己填，不让业务员代填。

### SOP-4 客户（外部，不用系统）

| 环节 | 客户的动作 | 对应系统状态 |
|---|---|---|
| 询价/还盘 | 跟业务员谈 | 报价 draft |
| 确认订单 | 签 PI/合同 | 合同 confirmed |
| 要货 | 通知发货时间 | 发货单 draft→confirmed |
| 改主意 | 明确说哪行不要 | 行 closed |
| 付款 | 按合同付款 | 收款 confirmed |

## 四、异常速查

| 情况 | 谁处理 | 怎么办 |
|---|---|---|
| 装柜装不下 | 保管员回填实发 → 业务员 | 补发或关行 |
| 客户不要某行 | 业务员 | 8501 关行，调度停产 |
| 库存不够发货 | 系统缺口预警 → 调度 | 排产/外协 |
| 同一料多张合同抢 | 业务员协商 | 先到先得按发货确认顺序 |
| 发货超合同 | 系统闸门直接拦 | 改数量或补合同 |
| 低价先发货 | 系统闸门直接拦 | 旧单不做了→关行；确需先发→老板特批（填原因，留痕） |
| 坏账 >1% | 老板 | 超额部分等额扣提成（R13） |

## 五、考核指标（建议）

| 指标 | 目标 | 哪里看 |
|---|---|---|
| 实发数回填及时率 | 装柜当天 100% | 发货单 draft 滞留清单 |
| 发货偏差 | ±5% 内 | 提成基数报表 |
| 合同按期完结率 | ≥95% | 未发完合同报表 |
| 关行留痕合规率 | 100% 填原因 | 审计日志 |
