# Demo 测试指南（四角色全流程）

> 配套自动化脚本：`python3 tests/demo_roleplay_test.py`（41 项断言，跑完自动清理）。
> 本文是**人工点界面**的走查路线，用于给同事演示或验收。
> 录入端 http://localhost:8082 ｜ 查询端 http://localhost:8501

## 角色分工速览

| 角色 | 主要操作页面 | 干什么 |
|---|---|---|
| 业务员 | 8082 基础资料/报价/合同/发货 | 建客户物料 → 报价 → 转合同 → 开发货单 → 关行 |
| 生产调度 | 8082 入库单 / 8501 合同执行 | 按合同排产、完工入库、看缺口 |
| 保管员 | 8082 出库单/入库单/辅料 | 调拨（本厂→临沂）、装柜出库、标签纸收发 |
| 老板 | 8501 首页 | 看价差预警、大额关行复核卡，必要时给特批 |

## 走查路线（13 幕，对应自动化 S0–S13）

1. **业务员·建客户**：8082 基础资料 → 新增客户。编号自动建议（字母+4位数字）；故意填 5 位数字会被拒（R12）。
2. **业务员·建物料**：基础资料 → 新增物料。填内径/厚度/长度自动推算外径单重；标签纸下拉选或手填（勾选自动建档）。
3. **业务员·报价**：报价录入 → 选客户选物料、填公斤价系数 → 单价=单重×系数自动算。付款条件/包装条款下拉。
4. **业务员·转合同**：报价列表点"转合同" → 合同生成，源报价变"已转合同"不能再转。
5. **生产调度·入库**：入库单 → 类型"生产完工" → 必须挂合同；合同外的物料选不上（选了也被拒）。
6. **保管员·调拨**：出库单类型"调拨"（本厂仓，填调拨号）→ 入库单类型"调拨"（临沂仓，同一调拨号）。两单必须同号配对。
7. **业务员·超发拦截**：发货单发货量填超过合同未发量 → 整单拒绝，数据库不动。
8. **业务员·正常发货**：按未发量发货 → 合同自动变"发货中"，已发数回写。
9. **保管员·装柜出库**：出库单类型"销售出库"（临沂仓）→ 选发货单，物料下拉只显示该发货单的料；选别的料被拒。
10. **老板·低价先发货**：同客户同物料有高价旧合同未发完时，给低价新合同开发货单 → **拦截**；确需先发：勾"老板特批"+填原因才放行（审计留痕）。
11. **业务员·关行**：8501 合同执行 → 选合同 → 关闭某行。原因必填；放弃余量 >5% 会上老板首页复核卡；关了的行不能再发货；全行了结合同自动"已完成"。
12. **业务员·收款**：基础资料/收款录入 → 挂合同。报表中心"业务员提成基数"按**实际发货重量**统计吨位（±5% 偏差提醒）。
13. **保管员·标签纸**：合同录入提交时提示标签纸需求/缺口 → 辅料页采购入库 → 生产领用出库 → 库存自动计数。

## 演示时两个推荐验证点

- 8501 首页：价差预警卡（第 10 幕后出现）和大额关行复核卡（第 11 幕后出现）。
- 8501 单据链路图：按合同选 SC 号，报价→合同→入库→调拨→发货→出库 全节点卷数/吨位一图看清。

## 红线

- 自动化测试只能用专用编码段（客户 Z9999 / 物料 M-Z9999-* / 单据 *-TEST*），脚本开跑前有冲突预检，撞上真实数据会主动中止。
- 2026-08-14 教训：测试编码段不得使用真实客户段（T7001 事件：真实客户物料险些被当测试数据清理）。
