# 远程访问速查卡（给团队同事）

> 你不需要装任何软件，只要一个浏览器（Chrome / Edge / Safari 都行）。

---

## 打开系统

在浏览器地址栏输入（同事/部署者会给你这个地址）：

```
http://你的域名:8080
```

例如：`http://inventory.viewdns.net:8080`

> 地址里有 `http` 不是 `https`，照着输就行，别漏掉 `:8080`。

---

## 登录

打开后是登录页面，照下表填（具体用户名密码问部署者）：

| 字段 | 填什么 |
|---|---|
| 数据库系统（System） | **MySQL** |
| 服务器（Server） | **db**（就这两个字母，小写） |
| 用户名（Username） | **inventory**（或部署者给你的账号） |
| 密码（Password） | **部署者告诉你**（不是 NAS 的密码，是数据库密码） |
| 数据库（Database） | **inventory_db** |

填完点 **登录**（Login）。

---

## 进去之后怎么看数据

登录成功后，左边会列出所有表：

| 你想看什么 | 点哪个表 |
|---|---|
| 物料/产品（规格、米重等） | `products` |
| 客户信息 | `customers` |
| 销售合同 | `sales_contracts`、`sales_contract_items` |
| 出入库流水 | `stock_in`、`stock_out` |
| 当前库存 | `inventory` |
| 报关/发货 | `shipping_records` |
| 收款记录 | `receipts` |

**基本操作：**
- 点表名 → 看全部数据
- 点 **选数据（Select data）** → 可以加筛选条件查
- 点 **导出（Export）** → 存成 Excel/CSV

> 字段含义不懂的，看 [docs/GLOSSARY.md](GLOSSARY.md)（术语表）和 [DATA_MODEL.md](DATA_MODEL.md)（数据模型）。

---

## 常见问题

### 网页打不开 / 一直转圈
1. 确认地址没输错（尤其 `:8080` 别漏）
2. 可能是部署者在维护，等几分钟再试
3. 还不行，截图发问部署者

### 登录提示"Access denied"（拒绝访问）
用户名或密码错了，找部署者确认。

### 数据是空的
还没灌入业务数据，找部署者让他导数据。

### 想修改数据怎么办
**不要自己改！** 数据库改错了影响所有人。需要改数据/录入新数据，找部署者统一处理。
